# Quick reference — elevator pitches

Copy/paste for decks, one-pagers, and CRM snippets. Full detail lives in each module page.

| Module | Pitch |
|--------|-------|
| Cultivation & Plant Map | See every room and strain group on one map — move plants, flip phases, and flag issues without leaving the floor. |
| Harvest Pipeline | Plan the cut, weigh on harvest day, allocate flower vs frozen, hang, bin, and hand off to trim — one pipeline. |
| Trim Sessions | One live session — multiple batches, assigned trimmers, flower/shake/waste weighed as you go, unfinished work rolls over. |
| Extraction | Template the process, start from inventory, check in weights on steps, finish into packages — plan washes backward from finished goods. |
| Packaging & Compliance | Finished inventory with lab states, audited adjusts, and plant/package tags — compliance trail built as you work. |
| Ordering & Procurement | Multi-store POs from vendor menus and POS sales velocity, plus AI-drafted biomass supplier email threads. |
| SOPs | Encode grow and extract as reusable templates — cultivation calendars and extraction process libraries with presets. |
| Reports & Analytics | Weekly trim labor productivity and cost-per-pound from the same sessions the floor just submitted. |
| AI & Voice | Talk to the facility — chat or mic — and confirm structured actions before they hit the database. |
| LLM Plugin | NeuroCann inside ChatGPT, Claude, Claude Code and Cursor — free planners with no account, your live facility after a one-time link, tasks with consent. |
| Tasks | Capture work that still needs a human, with assignees, due dates, and hybrid physical-then-digital completion. |
| Supplies | Par-level inventory for non-cannabis consumables across extraction, cultivation, and facility pools. |
