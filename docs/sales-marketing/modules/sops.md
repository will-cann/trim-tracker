# SOPs

**Elevator pitch:** Encode how you grow and extract as reusable templates — phase-lane cultivation calendars and extraction process libraries with industry presets.

## Who it's for

Cultivation leads, extraction managers, ops owners who want tribal knowledge out of binders and Slack.

**Nav:** SOPs · Universal access

## Problem

Process lives in people's heads. New hires recreate mistakes. Extraction runs and cultivation weeks look different every cycle because nothing is templated.

## Value

Cultivation SOPs as a phase × track calendar (feeding, training, IPM, environment, milestones). Extraction SOPs as multi-step process templates that actually start runs. Presets so operators aren't staring at a blank editor.

## Key capabilities (shipped)

- SOPs hub with domain tabs; Cultivation and Extraction available
- Cultivation SOP builder: phase durations (nursery / veg / flower / dry), track lanes, week grid, quick-add presets, recurrence, spans, env targets, critical flags, optional completion actions and supplies on events
- Extraction process templates: multi-step, accepted inputs / producible outputs, yields, durations, equipment, supply requirements, duplicate/edit
- 18+ preset extraction SOPs seeded per company
- Extraction workspace starts runs from these templates

## Status / domains

Templates: active presets vs custom (presets not deletable)  
Processing / Compliance / Facility domains: UI shows Coming soon

## Demo script

1. Open Cultivation SOP → show week lanes with IPM scout + flush milestones.
2. Switch to Extraction → open a preset (fresh frozen → bubble → rosin) and walk steps.
3. Start an extraction run from that template; show inputs/outputs linkage.
4. Be honest if asked about auto-task launch: cultivation SOPs are authoring/storage today; extraction templates drive live runs.

## Talking points

- "Cultivation SOPs aren't a flat checklist — they're a calendar with tracks."
- "Extraction presets mean you're not inventing ice-water steps from scratch."
- "The template that defines the process is the same one that starts the run."

## Differentiators

- Phase × track cultivation calendar
- Extraction presets tied to product-catalog material types
- Steps can declare supplies and completion actions (schema + editor support)

## Do not claim

- That cultivation SOPs auto-generate tasks when "launched" (empty-state copy may imply this — launch → task generation is not wired)
- That Processing / Compliance / Facility SOP domains are live
- That SOPs auto-execute METRC compliance steps
- That cultivation SOPs are a live batch schedule engine on the plant map today
