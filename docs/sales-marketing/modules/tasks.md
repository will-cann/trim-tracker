# Tasks

**Elevator pitch:** Capture anything that still needs a human — from AI/voice or manually — with assignees, due dates, and hybrid completion actions.

## Who it's for

Floor technicians through managers. Anyone who owns physical work that software can't finish alone.

**Nav:** Tasks · Universal access

## Problem

Not every facility action is digital. Scouting, cleaning, METRC paperwork, supplier follow-ups, and equipment checks fall through Slack and sticky notes.

## Value

AI can create tasks mid-conversation. Completing a physical task can fire a digital follow-up (`onCompleteAction`) — physical-then-digital workflows without a second app.

## Key capabilities (shipped)

- Human task CRUD
- Statuses: pending → in_progress → completed
- Priorities; 15+ categories
- Filters; cards / table / calendar views
- Saved task views
- Assign to team members
- `onCompleteAction` executed on complete
- AI: create / update / delete human tasks
- Supplier outreach reminders from Ordering cron land as tasks

## Demo script

1. From AI: "Remind the trim lead to sanitize stations before Friday's session."
2. Show task card with assignee, due date, priority.
3. Complete a hybrid task and show the on-complete digital action firing (if demo data has one).
4. Show calendar / saved views for a manager.

## Talking points

- "If it still needs a person, it becomes a task — not a lost chat message."
- "Finish the physical step; the system can queue the digital follow-up."

## Differentiators

- Tasks born from the same AI that runs ops mutations
- Hybrid completion actions bridging floor work to system state
- Ordering cadence reminders feed the same queue

## Do not claim

- Full project management / Gantt / resource leveling
- That cultivation SOPs auto-launch task sets today
- Push notification delivery for due dates (roadmap)
