# Harvest Pipeline

**Elevator pitch:** Plan the cut, weigh on harvest day, allocate flower vs frozen, hang, buck into bins, and hand off to trim — one pipeline.

## Who it's for

Harvest and post-harvest techs; managers for submit → hang approval; cultivation for planning; extraction for the frozen pathway.

**Nav:** Harvest · Department: cultivation  
**Also:** Harvest Day cockpit (live weighing)

## Problem

Harvest day loses wet weights, waste, contamination notes, and dry-room destination across clipboards and after-the-fact METRC paperwork.

## Value

A six-stage pipeline plus a dedicated weighing cockpit. Flower and fresh frozen split in the same harvest. Bins bridge hanging to trim with cure logs and moisture.

## Key capabilities (shipped)

- Kanban + table + drying schedule views
- Six stages: Planning → Cutting → Submitted → Hanging → Final Prep (bucking) → Completed
- Pathways: dry flower, fresh frozen, or mixed (frozen skips hanging/bucking visually)
- Create harvest from flowering plants or manually (license, strain, plant count, drying location)
- Allocations: Flower / Frozen / Both with target weights
- Waste categories (contamination, biomass, post-harvest)
- Harvest Day cockpit: multi-batch tabs, per-plant or bulk wet weight, drying room, allocation, waste, harvest-level contamination flags, fresh-frozen package creation with optional tags
- Submit batch → manager approve harvest day → hanging with drying day counters
- Bins: create/buck, cure logs (burp / aerate / inspect / note + moisture), mark ready, send to trim
- Convert flower allocation or ready bin → trim entry

## Status workflows

Harvest: planning → cutting → submitted → hanging → bucking → completed  
Bins: curing → ready → in_trim → completed  
Allocations: pending → in_progress → completed

## Demo script

1. Drag a planned harvest into Cutting; open Harvest Day; weigh plants; allocate Flower vs Frozen.
2. Flag powdery mildew / bud rot; log stem waste.
3. Submit → approve → hanging day counter; move to Final Prep → create bins → burp with moisture.
4. Frozen path: create fresh-frozen packages from the Harvest Day right column.
5. In AI chat / ambient review: "Plant 7 is 512 grams, has some PM."

## Talking points

- "Harvest Day is a cockpit for gloved hands — not a form buried in a card."
- "One harvest can feed dry flower and the freezer."
- "Bins aren't an afterthought — cure logs and moisture sit between hanging and trim."

## Differentiators

- Flower + fresh-frozen split on one harvest record
- Dedicated Harvest Day weighing surface
- Bin cure schedule tied to trim handoff

## Do not claim

- Hands-free ambient auto-apply of weights inside Harvest Day (AI proposes weights for confirm; cockpit mic fills the number field — ambient does not write directly into the cockpit)
- Live METRC harvest auto-submit
- Full plant-map pathogen catalog on Harvest Day flags (harvest-level: PM / bud rot / insects / other)
- Free drag from submitted → hanging (approval-gated)
